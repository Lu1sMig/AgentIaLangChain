# Ingeniería de Agentes y Automatización con IA - ONE AI FOR TECH

Programa de Alura diseñado en el aprendisaje de Inteligencia Artificial, mediante la creación de soluciones autónomas y automatizadas.  
* Agentes Inteligentes y LLMs: Aprenderás a construir agentes capaces de tomar decisiones, utilizar herramientas externas y ejecutar tareas de forma autónoma usando LangChain y LangGraph.  
* Automatización e Integraciones: Dominarás n8n para crear flujos de trabajo personalizados, integrar APIs, conectar servicios y automatizar procesos diarios con apoyo de IA.  
* Habilidades Técnicas Clave: Trabajarás con web scraping, gestión de estados, uso seguro de credenciales y arquitecturas de múltiples agentes con lógica condicional.  
* Proyectos Prácticos: Desarrollarás proyectos reales y pipelines inteligentes para fortalecer tu portafolio, capacitándote para crear soluciones integrales de extremo a extremo.
